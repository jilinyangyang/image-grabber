为什么需要图提取？

电商详情页的图片分散、无法批量保存、格式不统一，手动处理费时费力。

图片分散

商品图散落在详情页各处，既有普通图，也有懒加载图、背景图，肉眼难找全。

保存繁琐

一张张右键另存、手动重命名，几十张图片要重复操作几十次，极易遗漏。

格式不统一

jpg、webp、png 混在一起，不同用途需要统一格式时，还得逐个转换。

图提取（ImageGrab）是一款 Chrome 浏览器扩展，专为电商购物者与运营设计。它能在淘宝、京东、拼多多商家版的商品详情页右下角提供一个「获取图片」按钮，点击即可抓取页面全部商品图，并在独立画廊页中集中预览、勾选，最后一键批量下载为 PNG 高清图或打包成 ZIP，把繁琐的保存过程变成一次点击。

核心功能

六大能力，覆盖从提取到下载的完整链路。

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src、背景图等懒加载来源。

智能过滤

自动排除图标、Logo、占位图与过小图片，只保留真正的商品图。

集中预览

所有图片在新画廊页网格化展示，缩略图 + 尺寸信息一目了然。

自由勾选

支持全选、反选、按需勾选，只要想要的图，不要的都排除。

统一 PNG

jpg、webp 等格式自动经 canvas 转换为 PNG，输出格式统一。

批量下载

一键保存到本地，文件名自动编号（商品图_001.png），也可打包为 ZIP。

安装步骤

四步即可启用，全程免费，无需注册账号。

  1. 1

    下载插件压缩包并解压

    点击上方「下载插件」获取 ImageGrabber.zip，解压到一个不会移动的本地文件夹。

  2. 2

    打开扩展管理页

    打开 Chrome，在地址栏输入 chrome://extensions 并回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择第 1 步解压出的文件夹，即可完成安装。
